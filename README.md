# HR Attrition & Burnout Analytics: Apex Global Industries

## 📌 Project Overview
This project is an end-to-end data analytics solution designed to identify the root causes of employee attrition at Apex Global Industries. By analyzing HR metrics, I uncovered a critical flight risk among top performers and built an executive dashboard to guide retention strategies.

## 🛠️ Tech Stack
* **Database:** SQL (Data extraction and complex aggregations)
* **Data Analysis:** Python (Pandas, Matplotlib, Seaborn for exploratory data analysis)
* **Data Visualization:** Power BI (DAX, Interactive Executive Dashboards)

## 📊 Key Business Insights
1. **The Burnout Flight Risk:** Top-performing employees with poor work-life balance are quitting at a rate of ~36%, nearly triple the rate of those with a healthy balance.
2. **The Loyalty Penalty:** Analysis revealed an inverse relationship between employee tenure and percentage salary hikes, disincentivizing long-term retention.
3. **The "High Effort, Low Reward" Trap:** Isolated a high-risk group in the Sales department working consistent overtime for sub-14% raises, leading to a catastrophic 40%+ attrition spike.
